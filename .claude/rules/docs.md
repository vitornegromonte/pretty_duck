# Documentation standards

## Documentation

- Update `README.md` ("Findings so far"), the ADR in `docs/adr/`, and `docs/method.tex` when a result or a decision
  changes. Use the same numbers in all three.
- Describe what is known and what is a hypothesis. Do not write a hypothesis as a result.
- Write comments that explain why, not what. Remove comments that repeat the code.
- Keep the docstring and the command example at the top of each script current.
